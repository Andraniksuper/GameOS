GameOS

A lightweight, read-only live gaming operating system built on Arch Linux, optimized for distraction-free retro play.

Download on GitHub

🎮 PlayStation-Style XMB UI

Boots directly into a clean, modern, and snappy graphical interface powered by RetroArch for seamless navigation.

🔒 Built for Focus

Strict lockdown rules block system terminals, virtual console shortcuts, cheats, and time-rewind features.

⚡ Ventoy & USB Ready

Runs live straight from your USB flash drive entirely in RAM without modifying your machine's primary internal drives.
